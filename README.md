# Resultatenketen Digitale interactie van de overheid

Interactieve weergave van de resultatenketen **Impact → Outcome → Output**.

- Klik op een blok: de verbonden blokken in de andere lagen lichten op en er schuift een toelichting in.
- Lijndikte geeft de sterkte van de samenhang weer (sterk / gemiddeld / beperkt).

De koppelingen, sterktes en toelichtingen zijn een voorstel.
